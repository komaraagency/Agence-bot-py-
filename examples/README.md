# Dossier d'exemples

Placez vos photos d'exemples ici (format .jpg ou .png).

Le bot Telegram les enverra automatiquement quand un client tape `/exemples`.

## Comment ajouter des photos

1. Glissez vos images dans ce dossier `examples/`
2. Nommez-les clairement : `logo_resto.jpg`, `affiche_mode.png`, etc.
3. Committez et poussez sur GitHub
4. Le bot les affichera automatiquement

## Format supporté
- .jpg, .jpeg, .png
- Taille recommandée : max 5MB par image
